# OnlineShop

OnlineShop (PlantShop) — интернет-магазин растений на ASP.NET Core. Проект включает клиентский
сайт, административную панель и отдельный REST API.

## Основные возможности

- Каталог товаров с категориями, характеристиками, фильтрами, сортировкой и поиском.
- Карточки растений с фотографиями, описанием, отзывами и рейтингом.
- Корзина для зарегистрированных пользователей и гостей, избранное и промокоды.
- Оформление и история заказов, личный кабинет и редактирование профиля.
- Управление товарами, категориями, остатками, заказами, отзывами и пользователями.
- Административная сводка с показателями продаж и графиками.
- Выбор адреса доставки на карте.
- Уведомления о событиях магазина и журнал работы приложения.
- Адаптивный интерфейс для мобильных и настольных устройств.

## Стек

- **C#, .NET 10, ASP.NET Core MVC** — клиентский сайт и административная панель.
- **ASP.NET Core Web API** — отдельный REST API.
- **Entity Framework Core, Microsoft SQL Server** — хранение данных и миграции.
- **ASP.NET Core Identity** — учётные записи и роли.
- **SixLabors.ImageSharp** — обработка фотографий товаров и профилей.
- **Serilog** — структурированное журналирование.
- **Bootstrap, JavaScript** — интерфейс и клиентская логика.
- **Yandex.Maps API** — отображение карты и выбор адреса.
- **xUnit, GitHub Actions** — тестирование и автоматическая сборка.
- **Docker, Docker Compose** — контейнерное развёртывание.
